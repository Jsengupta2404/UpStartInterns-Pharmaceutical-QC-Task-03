
# UpStartInterns – Pharmaceutical Quality Control
## Task 03: Out-of-Specification (OOS) Investigation

### Project Overview
This project presents an educational, retrospective analysis of a published pharmaceutical Blend Uniformity OOS investigation.

The case examines laboratory investigation, potential assignable causes, root-cause identification, Corrective and Preventive Actions (CAPA), and effectiveness verification.

### Case Study
The investigation concerns blend-uniformity results for anonymised XYZ Tablets USP. The reported investigation identified API adsorption onto specific volumetric flask surfaces as the principal root cause, with incomplete sample mixing as an additional contributing factor.

### Key Areas Covered

### Important Note
This is an educational retrospective analysis of a published investigation. It is not an original laboratory investigation or a GMP-controlled OOS record. Numerical findings are attributed to the original publication.
